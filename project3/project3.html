The Importance of Responsive Design

Responsive design is incredibly important because people judge a website by how it looks and how it handles. A lot of customers shop both on their phones and their computers, so it's very important to have a website that handles well in most screen settings. Especially for small businesses, I think that people judge how well their site works, and based on that, whether the website is trustworthy.



Google Analytics Reports


User Acquisition

A user acquisition report is a report collected by Google Analytics. It is used to determine how users who are specifically new to a website interact with it.

Events Report

An event report is a report that makes a note of anytime that a user triggers an event. It measures how many times specific userss trigger events, the type, and what their general surfing on the site is like. Event Report

Pages and Screen Report

A pages and screen report explains what pages a user is landing on when they come to the website. The report also measures every page that the users visits, and the order in which they visit pages. It also measures how many views particular pages get, and how much a single user visits different pages. Pages and Screen Report
